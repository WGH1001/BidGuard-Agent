## 一、四项升级的最终融合定案（兼顾实战惊艳度与 85 项单测零回归）

### 1. 【升级点 4】F1 评分表 100 分守恒校准 + F2-2 最高限价 11/11 语料大满贯

- **评分表强守恒拼合**（core/tender_extractor.py）：当 docx 表格型评分细则合计分值落在 (0, 100) 之间且表内无"价格/报价"分项时，用正则在评标章正文检索价格分值（如滁州托育正文的 10 分价格分公式）；严格执行强守恒约束——**仅当 表格分 + 正文价格分 == 100 时才自动补入价格评分行，绝不强行凑数**。
- **江苏政采模板跨格预算提取**（core/price_extractor.py）：依据《政府采购法实施条例》第 33 条（未单独设定最高限价时以采购预算作为法定上限），在 `_extract_from_docx_tables` 与文本正则中补齐江苏省级模板（科技一件事、江苏固废）"预算金额/采购预算"跨格与分包写法，将 11 份真语料的 price_cap 提取率从 9/11 拉满至 **11/11（100%）**。

### 2. 【升级点 2】Word (.docx) 内嵌证照与社保图片"段落就近吸附"离线 OCR

融合定案（core/parser.py）：

- **按 w:drawing 关系 ID 原位吸附**：遍历 doc.paragraphs（及表格单元格段落）时，检测段落 XML 内是否含 `<a:blip r:embed="rId..."/>`；若有，直接从 `doc.part.related_parts[rId]` 取出图片字节流，将 RapidOCR 识别出的文字**紧跟在该段落文本下方**（而非堆在全文末尾），使"附件：营业执照 / 社保证明"标题与图片内的有效期、月份天然同段相连。
- **双重尺寸过滤 + 伴生缓存**：仅对字节数 > 20KB、宽高均 >= 200px 且长宽比在 1:6 ~ 6:1 之间的图片执行 OCR（自动过滤页眉 Logo、印章碎片与细长分割线），识别结果按图片 SHA1 缓存在 `<原文件>.media.ocr.json`，二次解析毫秒级秒读。

### 3. 【升级点 3】F4 缺证明材料支撑（MISSING_EVIDENCE）探针与单测防回归保护

融合定案（core/response_checker.py）：

- **触发条件与防回归保护**：当招标要求命中 `须提供|应提供|提供.*?(?:证书|检测报告|截图|证明材料|承诺函|复印件|扫描件)` 且初判为 RESPONSE_OK 时，检查投标书除照抄原句外是否包含佐证锚点（如 见附件、详见、证书编号、报告编号、或全文 OCR 检出对应证书正文）。
  （注：现有单测 test_response_checker.py 和 test_deviation_exporter.py 的 mock 投标书写的是"（我方完全满足，证书见附件）"，包含 见附件 锚点，因此会被正确识别为"已附佐证索引"，确保既有 85 项单测 100% 零回归！）
- **定级与偏离表兼容**：缺佐证材料产出 `code='MISSING_EVIDENCE'`、`severity='warning'`（扣分/废标隐患预警，不武断定死为 error）；同时在 star_results 中保持主状态为 `'RESPONSE_OK'` 并附 `evidence_warning` 标记，使 F5 导出的《技术与商务偏离表.docx》在"偏离情况"列保持合法合规的 **无偏离**，而在"我方投标响应"列末尾温和括注 **（注：请核实已附对应证明材料）**。

### 4. 【升级点 1】F4 + F7"先快后慢"门控三级混合检索（core/hybrid_retriever.py，新建）

融合定案：

- **严格门控（Gate Filter）防时延爆炸**：
  - 在 F4 中，85% 以上通过条款号、标题或高 2-gram 重合度直接命中的条款 **0ms 直通放行，绝不触发混合检索**；
  - 仅对 F4 初筛未命中的"疑似漏应答候选"以及 F7 的自然语言提问，才启动 hybrid_retriever。
- **三级自适应检索链**：
  - **Level 1（0-Token 离线极速层，<3ms）**：BM25 + 40 组招投标领域同义词扩展（如 项目经理↔项目负责人、质保期↔免费维保期、高可用灾备↔双活集群故障接管、信创↔国产化自主可控）；
  - **Level 2（有 API Key 时可选激活）**：基于文件 SHA256 缓存的 Embedding 向量余弦粗筛（`data/cache/{hash}.emb.npy`）+ Rerank 精排 Top-3；
  - **Level 3（无 Key / 离线单测兜底）**：自动停留在 Level 1，保证离线环境零报错、秒级返回。
