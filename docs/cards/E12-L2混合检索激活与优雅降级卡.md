## 1. 业务背景

1. 当前（切换公司统一网关前）使用智谱官方 API（`config/models.yaml` demo env），支持 Chat 与 `embedding-3` 向量接口；
2. 后续切换公司统一网关（prod env，`http://10.0.2.81:3000/v1`）后，网关仅代理 20 个通用 Chat 模型，**无向量模型**（embedding 0、rerank 0）；
3. 要求：有向量模型时自动激活 Level 2 混合检索（语义精排提效）；无向量模型或切回公司网关时**全自动、无感知优雅降级**到 Level 1（BM25 + 45 组同义词）。

现状缺口：`_try_level2_embedding_rerank`（E2 交付）激活条件是 client 有可调用的 `embed`/`embeddings` 方法，而 `LLMClient` 只封装了 chat/chat_stream —— **L2 从未真正通电**。

## 2. 开发任务

1. **`core/llm_gateway.py` LLMClient 补齐 `embed()` 方法**：
   - 遵循 OpenAI 兼容 `/v1/embeddings` 规范（OpenAI SDK 路径 `client.embeddings.create`；requests 兜底路径 POST `{base_url}/embeddings`）；
   - 向量模型名从 `env_config['models']['embedding']` 读取（`config/models.yaml` demo env 配 `embedding: embedding-3`；prod env 不配置即天然降级）；
   - `build_client_from_user_config` 追加**可选** kwarg `model_embedding=None`（不破坏既有调用方与签名兼容）；
   - 单次支持传入字符串或文本列表，统一返回 `list[list[float]]`；embedding token 计入用量账本（completion 计 0）。
2. **优雅静默降级守卫（`core/hybrid_retriever.py`）**：
   - `_try_level2_embedding_rerank` 增加**快速失败**：client.models 无 'embedding' 配置 → 不发请求直接 return None；
   - embed 调用任何异常（404 / Model not found / 网络超时 / 参数不支持）→ 被既有 `except Exception` 捕获静默 return None，**严禁向上抛出**，绝不能导致体检任务或 F7 追问中断；
   - `BIDGUARD_FORCE_ZERO_TOKEN=1` 强制 Level 1（既有行为保持）。
3. **保留 SHA256 磁盘向量缓存**：`data/cache/{sha256}.emb.npy`，同一标书向量只算一次（既有机制，不重做）。
4. **附带文档任务（顺手活，不另立卡）**：README 新增小节介绍 F7 六大工具与三级检索/Rerank 原理（六工具：search_tender / search_bid / locate_chapter / recalc_price / check_cert_expiry / cite_regulation，全部确定性函数；三级链：L1 BM25+45组同义词 <3ms → L2 SHA256缓存 embedding 余弦粗筛 Top-15 + 0.55×向量分 + 0.45×BM25 分融合精排 Top-3 → L3 离线/无配置静默回退 L1），数字与代码逐字一致。
