## 2. 升级点定案全文（逐字执行）

### 2.1 【升级点 3a】F4 缺证明材料支撑探针（core/response_checker.py）

- **触发条件**：招标要求命中 `须提供|应提供|提供.*?(?:证书|检测报告|截图|证明材料|承诺函|复印件|扫描件)`
  且初判为 **RESPONSE_OK** 时，进一步检查投标书除照抄原句外**是否包含佐证锚点**：
  （如 见附件、详见、证书编号、报告编号、或全文 OCR 检出对应证书正文）。
- **产出**：无佐证锚点 → 产出 `code='MISSING_EVIDENCE'`、`severity='warning'`
  （扣分/废标隐患预警，**不武断定死为 error**）。
- **数据结构契约**：`star_results` 中该条款**主状态保持 'RESPONSE_OK'** 并附 `evidence_warning`
  标记（标记值含提示语），下游 F5/B2 据此兼容展示。
- **防回归保护（关键）**：既有单测的 mock 投标书写的是"（我方完全满足，证书见附件）"，
  包含 **见附件** 锚点 → 必须被正确识别为"已附佐证索引"、**不产出** MISSING_EVIDENCE，
  确保既有测试 100% 零回归。

### 2.2 【升级点 1】三级混合检索器（core/hybrid_retriever.py，新建）

- **严格门控（Gate Filter）防时延爆炸**：
  - 在 F4 中，85% 以上通过**条款号、标题或高 2-gram 重合度**直接命中的条款 **0ms 直通放行，
    绝不触发混合检索**；
  - 仅对 F4 初筛未命中的"**疑似漏应答候选**"以及 **F7 的自然语言提问**，才启动 hybrid_retriever。
- **Level 1（0-Token 离线极速层，<3ms）**：纯 Python BM25 + **40 组招投标领域同义词扩展**
  （如 项目经理↔项目负责人、质保期↔免费维保期、高可用灾备↔双活集群故障接管、
  信创↔国产化自主可控 等——40 组为下限，你可在附件基线上按领域常识增补，需在回复中列出清单）；
- **Level 2（有 API Key 时可选激活）**：基于文件 SHA256 缓存的 Embedding 向量余弦粗筛
  （缓存落 `data/cache/{hash}.emb.npy`）+ Rerank 精排 Top-3；
- **Level 3（无 Key / 离线单测兜底）**：自动停留在 Level 1，保证离线环境零报错、秒级返回；
- **依赖纪律**：不新增任何 pip 依赖（BM25 纯 Python 自实现；embedding 走现有 openai 客户端）；
  缓存目录不存在时自动创建，写失败静默降级为不缓存。

### 2.3 【升级点 3b】F4 接入门控（core/response_checker.py）

- 直接命中（条款号/标题/高 2-gram 重合度）→ 0ms 直通，走现有判定链；
- 疑似漏应答候选 → 用 hybrid_retriever 在投标书侧做二次检索，**检索命中（含同义词改写）则改判
  RESPONSE_OK**（附检索证据），仍无命中才定 MISSING_RESPONSE / MISSING_EVIDENCE 探针链；
- 全程不得改变函数对外的入参与返回结构（新增字段走追加，不删改既有键）。

### 2.4 【升级点 1b】F7 接入（core/bid_react_agent.py）

- F7 自然语言提问的检索步骤接入 hybrid_retriever（先 Level 1，有 Key 且配置允许时 Level 2），
  检索结果作为 ReAct 工具的证据来源之一；ReAct 循环轮数上限、溯源绑定等既有机制**一字不动**。

## 3. 测试要求（tests/test_e2_hybrid_and_evidence.py）

1. **门控直通**：构造条款号/标题直接命中场景 → 断言未进入混合检索路径（可用计数桩或耗时断言）；
2. **同义词召回**：招标要求"项目负责人证书"、投标书写"拟派项目经理持有 XX 证书"（同义词改写、
   不抄原句）→ 断言 F4 判 RESPONSE_OK 零误报漏答；BM25 单元级断言 Level 1 <3ms 量级（逻辑断言即可）；
3. **MISSING_EVIDENCE**：投标书只喊"完全满足"无任何锚点 → 100% 产出 MISSING_EVIDENCE(warning)，
   且主状态 RESPONSE_OK + evidence_warning；带"见附件"锚点 → 不产出；
4. **F5 兼容**：构造 MISSING_EVIDENCE 场景跑 export_deviation_table → 偏离情况列保持"无偏离"、
   响应列末尾含"（注：请核实已附对应证明材料）"；
5. **Level 3 兜底**：无 Key 环境 → 全链路零报错（embedding 不触发）；
6. **零回归**：不修改任何既有测试文件。
