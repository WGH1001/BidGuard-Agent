## 1. 核心修复与增强目标

1. **单章 AI 撰稿瞬时容错重试**：`_draft_chapter_with_llm` 遇模型网关超时、网络抖动或残缺 JSON/`paragraphs` 为空时，自动执行 **最多 2 次重试**（合计 3 次尝试；每次重试前校验 `cancel_check()`），避免单章（如原北交大 04 包第三章）因并发抖动直接退化成一句话占位。
2. **彻底清除投标须知/澄清/评标计分规则混入实施方案**：
   - 修复 `_collect_scoring_topics` 优先摄入目录省略号窗、第一章招标邀请、投标人须知（`4.2 认真阅读…`、`5.1 澄清…`、`6.1 修改…`）及《计分方法/评标总则》的问题；
   - 按「真实含分值 `评分细则` / 评价指标窗优先」策略采集 PDF/文本型评分细则（如 `实施方案 0-9 分`、`售后服务方案 0-12 分`、`项目进度计划 0-11 分`、`培训方案 0-9 分` 等），并与第四章全量采购需求合理配额汇合。
3. **解除 4 处截断硬上限（L483 / L486 / L603 / L645）**：
   - `_plan_chapters_with_llm`：原目录参照上限 `12 → 30`、主题摘要上限 `18 → 40`；
   - `_draft_chapter_with_llm`：章节辅助明细表行上限 `12 → 36`；
   - `_draft_deviation_with_llm`：将原 `targets[:12]` 升级为**每批 ≤12 条分批循环拟稿**（每批前校验 `cancel_check()`），确保第 13 条及以后全部实质性偏离行均能生成 AI 初稿。
4. **AI 章节首段重复标题剥离**：新增 `_strip_duplicate_leading_title`，在撰稿解析及 `.docx` 渲染前自动剔除与外层 `Heading 2` 章节号/标题重复的冗余首行或首段。
5. **资格证明（第二部分）同名证书带角色合并去重 + 总览表 & 逐项独立附页/原件实图嵌入**：
   - 按规范证书名去重合并同名多次出现条目（如同时位于资格门槛与评分加分的「环境标志产品认证证书」），保留最高强制等级及多角色说明（如 `必交资格项 / 加分参考项`）；
   - 将 Word 第二部分从窄单元格表升级为 **「2.0 资格证明文件总览索引表 + 2.1~2.N 逐项独立附页（`Heading 2`）」**：
     - 台账关联了磁盘实际存在的 `.png/.jpg/.jpeg/.bmp/.webp` 原件图片 → 经安全路径校验后使用 `doc.add_picture(..., width=Inches(5.6))` 居中真实嵌入高清扫描图；
     - 关联了 `.pdf` 附件 → 渲染标准 PDF 原件随正本装订说明框；
     - 未上传原件 → 渲染整页宽单格标准扫描件粘贴装订框（含盖章与粘贴指引）。
   - `backend/routers/composer.py` 在导出 `.docx` 后、持久化 `blueprint_json` 前清洗剥离物理服务器路径 `attachment_path`，绝不将宿主路径暴露至 DB/前端 API；前端 [BidComposerView.vue](file:///e:/agent/BidGuard-Agent/frontend/src/views/BidComposerView.vue) 同步展示合并角色标签与逐项附页状态卡片。
