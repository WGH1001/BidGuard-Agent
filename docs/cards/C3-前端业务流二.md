## 3. 实现铁律

1. 契约以 FRONTEND.md 为准；types 逐字段对齐；禁 any。
2. 溯源展示沿用 C2 修正后的语义：**只有 quote_verified=true 才显示"✓已通过原文溯源"**，false 显示"未经溯源校验"，quote 空不渲染摘录块（RiskCard.vue 现行实现照抄风格）。
3. docx 页码 null → "字符偏移 @N"（用 formatPageOrOffset 最新版）；下载一律走 download.ts 的 blob 封装。
4. 401 清 token 跳登录；404 toast"不存在或无权访问"；审计接口 403 显示权限提示页内区块。
5. 视觉与蓝本明显差异化；严禁合同/甲方/乙方/审查报告等旧项目残留词。
6. 蓝本只参考机制（会话流组织、ReAct 步骤折叠、规则 CRUD 表单、审计分页表）。
7. **分两批输出**：第一批 = types.ts + index.ts + router（三个完整覆盖版）+ ReActSteps.vue + QaMessageList.vue + QaChatView.vue（约 2600 行），输出完停；第二批 = RulesAndCertsView.vue + ReportsAndAuditView.vue（约 1800 行）。文件严禁半截。
